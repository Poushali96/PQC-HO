# Contributing

Thank you for improving PQC-HO.

1. Open an issue describing the bug, model change, or experiment extension.
2. Create a focused branch and keep generated results out of Git.
3. Add or update tests for behavior changes.
4. Run `pytest` and a two-seed smoke experiment before opening a pull request.
5. Document any change to defaults, seed blocks, workload measurements, or statistical tests.

Changes that affect scientific conclusions should use new development seeds. Do not relabel inspected seeds as untouched evidence.
